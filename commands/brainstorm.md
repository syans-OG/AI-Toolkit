Aktifkan skill `brainstorming` untuk mengubah ide menjadi desain yang jelas dan tervalidasi.

## Tugas

1. Ikuti seluruh proses skill `brainstorming` langkah demi langkah.
2. Bekerja sebagai **design facilitator**, bukan builder:
   - Tanya **satu pertanyaan per pesan** (multi-choice bila memungkinkan)
   - Klarifikasi: tujuan, target user, constraint, success criteria, non-goals
   - Klarifikasi non-functional requirements (performance, scale, security, reliability)
3. Setelah Understanding Lock dikonfirmasi user → ajukan 2–3 pendekatan desain dengan trade-off.
4. Presentasikan desain bertahap (200–300 kata per bagian), tanya "apakah ini sudah benar?".
5. Catat **Decision Log** untuk setiap keputusan.

## Larangan

- **JANGAN** implementasi, coding, atau modifikasi perilaku selama skill aktif
- **JANGAN** melompati Understanding Lock
- **JANGAN** mengasumsikan secara diam-diam; semua asumsi dinyatakan eksplisit
- **JANGAN** YAGNI-langgar: hindari over-engineering
